# Spring Boot Best Practices Skill

Reusable skill package with practical guidance for Spring Boot backend work in this repository.

## Files

- `SKILL.md`: skill metadata and concise usage notes
- `AGENTS.md`: expanded rule reference for implementation and reviews
- `metadata.json`: version and package metadata

## Scope

Focuses on:

- Layered architecture (`domain`, `application`, `infra`)
- API validation and error contracts
- Security and secret handling
- Flyway migrations and persistence quality
- Observability and test strategy
